# מכונת תוכן שיווקי · מוק-אפ (משימה 5)

שלב 10 במסע, "מכונת תוכן שיווקי", אחרי השדרוג: ערוץ ומראה, תוכנית שבועית, תוכן (פוסט, קרוסלה, רילס), פלייר, ותזמון ופרסום לאינסטגרם ולפייסבוק.

- הרצה מקומית: לחיצה כפולה על `open-mockup.bat` (פורט 4187).
- המוק-אפ נפתח על השלב, בתוך המערכת. Shift+D פותח הערות למפתחים, מעבר מהיר בין המסכים ומתגים למקרי קצה.
- פרמטרים בקישור: `?view=step|home`, `?screen=opening|channel|look|plan|content|flyer|publish|done`, `?user=f` לפנייה בלשון נקבה.

הקבצים:
- `src/data.js` נתוני הדוגמה (מרחב שקט), 10 התבניות, הנושאים.
- `src/content.js` מבנה הפוסט, הקרוסלה והרילס, מגבלות המילים והבדיקות על כל טקסט.
- `src/art.js` הקריאייטיב בגודל האמיתי (1080×1350, 1080×1920) והפלייר.
- `src/step.js` מסכי השלב. `src/publish.js` הלוח, התזמון, החיבור ל-Meta ו-Grow.
